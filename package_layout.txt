
____________________Design Notes____________________

models/ implements the core message passing logic from Propositions 1, 3, and 4.

ops/ modularizes the algebraic and topological foundations: combinatorial complexes, neighborhood functions, and copresheaf morphisms (linear maps ρ).

train/ supports flexible experiment orchestration and includes custom loss functions like diffusion energies.

config/ allows YAML-based experiment setup for reproducibility.

examples/ provides usage demonstrations including datasets from MUTAG or synthetic CCs.

tests/ includes model-level and mathematical validation (e.g., verifying morphism compositions or CNM correctness).
